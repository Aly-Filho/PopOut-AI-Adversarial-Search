# PopOut-AI-Adversarial-Search

An Artificial Intelligence project focused on implementing adversarial search strategies and decision trees for the game PopOut (a Connect-4 variant). This repository includes a Monte Carlo Tree Search (MCTS) with UCT for game-playing and a custom ID3-based Decision Tree classifier developed from scratch.

✅ **Status: Complete & Ready to Run** *The code is fully complete, ready to be executed, and the assignment requirements have been successfully met.*

## 🚀 Getting Started & Execution Order

To follow the project's production order and understand the workflow, please **start with the `main.py` file**.

* `main.py`: This is the main entry point of the project. It serves as the principal report and the main script to run the implemented algorithms. 
* **Jupyter Notebooks (`*.ipynb`)**: Available for consultation. These notebooks contain further explanations, in-depth analysis, and detailed walkthroughs of the code logic.
* **ID3-Models (`*.json`)**: Represents the models created with different depths limitations.
* **dataset_winners (`*.csv`)**: The final dataset created to train the ID3 model.
* **iris (`*.csv`)**: Given by the teacher.
* **tree_ (`*.pdf`)**: Plotting of some of the ID3 models created on this project.
